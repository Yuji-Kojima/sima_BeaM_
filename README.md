# simaBeaM
信号と機械のよくわからんシミュレータ<br>
## ナニコレ
変な装置を使って変なシミュレーションができるよ<br>
semaVMの息抜きに作ってるよ<br>
## どう使うん
変な装置を辞書に置いて遊ぶよ<br>
### 操作方法
" **WASD** " *カメラを1マス移動する。*<br>
" **/** " *コマンド入力画面を出す。*<br>
" **クリック** " *座標と置かれている装置の内部名を表示する。*<br>

### コマンド集

*カッコの中身は必須でないもの*<br>

**n**:任意の数字<br>
**x,y**:座標用の整数<br>
**()内**:書かなくても実行できる<br>


|コマンド|オペランド|効果|
|---|---|---|
|`camera`| x,y |カメラ位置を指定の位置に移動する。|
|`put`| x,y,名前,(向き),(信号の強さ) |指定の座標に指定の装置を置く。|
|`del`| x,y |指定の座標の装置を削除する。|
|`cell`| n |画面表示のサイズを指定する。|
|`save`| 名前,開始x,y,終了x,y |指定の座標の装置をjson形式で保存する。|
|`load`| 名前,(x,y) |指定の座標に、json形式で保存されている装置を置く。 |


## 形式など
(**x座標**,**y座標**):<br>
 {"kind": "**装置の内部id**",<br> 
  "dir": "**東西南北、ewsn**",<br>
  "signal": **今受け取ってる信号の強さ(int)**},<br>
### リスト
|内部id|名前|効果|
|---|---|---|
|power|電源|信号を受け取っているとき周囲8マスに8の強さの信号を出す|
|abpower|絶対電源|信号にかかわらず周囲8マスに8の強さの信号を出す|
|unpower|反抗期電源|信号を受け取っていないとき周囲8マスに8の強さの信号を出す|
|beam|直線ビーム|信号を受け取っているとき、向いている方向に、8から1まで減衰する信号を出す|
|levelbeam|可変出力ビーム|信号を受け取っているとき、向いている方向に、受け取っている信号の強さから1まで減衰する信号を出す|
### 装置の追加
このシミュレーターは、アドオンとして機械を追加できる。<br>
#### 辞書
"**装置の内部id**":{<br>
      "name":"**装置名**",<br>
      "pass":**True or False**,　(信号が通過するかの判定、現段階ではまだこの部分を活用する装置がない)<br>
      "on":**onの時実行したい関数**,<br>
      "off":**offの時実行したい関数**<br>
              }
#### 関数
def **辞書で指定した関数名**(**装置本体のx座標,y座標,向き,受け取っている信号の強さ,世界全体のオブジェクトが入った辞書,世界全体の信号が入った辞書**):<br>
必ず、*(**信号を出力する場所のx座標,y座標,信号の強さ**)を含んだリストをreturnで返すこと(空でも可)。*<br>
